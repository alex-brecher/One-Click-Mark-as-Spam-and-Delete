## Category

Workflow & Planning

## Language

English

## Description

Remove unwanted Gmail messages with one clear action.

One-Click Spam & Delete adds a Spam & Delete control to Gmail’s main toolbar. Use it with an open message or selected inbox rows.

MAIN FEATURES

• Reports the selected message as spam
• Moves the message to Trash after the spam action
• Works with one open message or multiple selected messages
• Handles Gmail’s spam and block dialogs
• Stops the Delete step if Gmail opens a different conversation
• Offers an Undo action through Gmail

CONTROL OPTIONS

• Place the control in the Gmail toolbar or on the page
• Select one of four control styles
• Move the control to your preferred position
• Use Ctrl+Shift+S on Windows or Cmd+Shift+S on macOS
• Turn on a confirmation prompt for each action
• Choose whether the extension blocks the sender

PRIVACY

• No analytics, advertising, or tracking
• No external network requests
• No collection or sale of personal information
• Local processing in the Gmail tab
• Chrome sync stores only extension settings

The extension uses Gmail’s visible controls. It does not use the Gmail API or send message content to a server.

## Single purpose

The extension adds one Gmail control that reports selected messages as spam and moves them to Trash.

## Permission justification

`storage`: Saves the user’s control style, position, and action preferences with Chrome sync.

Host access to `https://mail.google.com/*`: Adds the control to Gmail and runs the visible Gmail actions selected by the user.

## Data-use declaration

The extension does not collect or transmit user data. It processes Gmail page elements locally to provide its single purpose.
