Keyboard shortcut

Ctrl+Shift+S or Cmd+Shift+S while Gmail is focused

This is a fixed in-page shortcut — Chromium’s commands API is not available without a service worker or broad host permissions, so rebinding the shortcut in chrome://extensions/shortcuts has no effect on this extension. Tab to the widget and press Enter or Space to fire it; hold Ctrl with ←/→ to move it along the toolbar.

Open an email or check one or more rows, then fire the widget: it runs Gmail's Report Spam, dismisses the follow-up dialogs, and clicks Delete — the same workflow you'd do by hand.
