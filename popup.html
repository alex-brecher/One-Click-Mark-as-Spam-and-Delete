Keyboard shortcut

Loading... Use this shortcut while Gmail is focused.

Chrome manages this shortcut. You can change it on the Chrome extension shortcuts page. The command does not run while you type in Gmail.

Press Tab to focus the widget. Press Enter or Space to run it. Hold Ctrl and press ← or → to move the toolbar widget.

Open an email or check one or more rows, then fire the widget: it runs Gmail's Report Spam, dismisses the follow-up dialogs, and clicks Delete — the same workflow you'd do by hand.
