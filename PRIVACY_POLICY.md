# Privacy Policy for One-Click Spam & Delete

Effective date: November 16, 2026

One-Click Spam & Delete does not collect, sell, share, or transmit personal information.

The extension reads the Gmail page only to add its control and run the Gmail actions that the user selects. All processing occurs in the browser. The extension does not send email content, account information, or usage data to an external server.

The extension stores user settings with `chrome.storage.sync`. These settings include the control style, control position, and action preferences. Google manages the synchronization of this data through the user’s Chrome profile.

The extension does not use analytics, advertising, tracking, cookies, or external network requests.

## Optional feedback form

The popup has "Suggest an idea" and "Report a problem" links. They open a feedback form at `https://feedback.netrition.com` in a new browser tab. The extension does not send anything to that page except the extension name, the version number and the type of feedback, which are placed in the page address.

The form sends a report only when you press Send. A report contains:

- the text you write
- your name and email address, only if you enter them (both are optional)
- a screenshot, only if you add one
- your browser's user agent, your window size and the extension version

Reports are stored by the developer on Cloudflare and are emailed to the developer through SparkPost. They are used only to read, answer and act on the feedback. They are not sold or shared for advertising. Do not include email contents or other personal details that you do not want to share. To ask for a report to be deleted, open an issue in the repository below.

The extension uses access to `https://mail.google.com/*` only to provide its single purpose. This purpose is to add a Spam & Delete control to Gmail.

For support or privacy questions, use the repository issue tracker:
